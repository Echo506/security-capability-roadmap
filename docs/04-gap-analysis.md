# Gap Analysis

| Capability | Gap | Risk Impact | Recommended Action | Owner | Dependency |
|---|---|---|---|---|---|
| IAM | Incomplete MFA coverage and no formal privileged access governance | High | Enforce MFA, define access review cycles, and evaluate PAM controls | Identity Team | Accurate identity inventory |
| Cloud Security | No centralized cloud misconfiguration monitoring | High | Define cloud baseline and implement CSPM pilot | Cloud Security Team | Account inventory and cloud tagging |
| SIEM | Limited high-priority detection coverage | High | Add detections for phishing, credential misuse, ransomware, and cloud IAM anomalies | SOC | Log onboarding and use-case owners |
| Vulnerability Management | Remediation timelines are inconsistent | Medium | Define SLA tiers and reporting process | IT Operations | Asset criticality model |
| Data Protection | Data classification is incomplete across business units | High | Create classification model and align handling requirements | GRC | Business data owners |
| GRC | Risk ownership and evidence management are fragmented | Medium | Standardize risk register governance and control evidence collection | GRC | Executive sponsorship |
